# 🚀 NOVAS GAME ULTRA

NOVAS GAME ULTRA est un jeu de tir spatial développé avec React offrant une expérience arcade moderne avec des fonctionnalités avancées.

## Fonctionnalités

- 🎮 Plusieurs modes de jeu
- 🏆 Système de succès (Achievements)
- 📈 Progression avec niveaux et expérience
- 💰 Boutique intégrée
- 🎯 Missions quotidiennes
- 🌍 Support multilingue
- 🎨 Thèmes personnalisables
- 🔊 Effets sonores dynamiques
- 👤 Gestion du profil joueur

## Technologies utilisées

- React
- JavaScript
- LocalStorage
- Web Audio API
- CSS

## Objectif du projet

Ce projet a été conçu pour explorer le développement de jeux web modernes et proposer une expérience utilisateur immersive directement dans le navigateur.
